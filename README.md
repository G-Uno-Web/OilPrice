# 今日油价查询

一个免安装、单文件的国内油价查询网页，开箱即用。

## 功能一览

| 功能 | 说明 |
|------|------|
| 📍 IP 自动定位 | 打开页面自动识别所在省份并展示当地油价（三层定位容错，失败可手动切换） |
| ⛽ 常用标号 | 92# / 95# / 98# 汽油、0# 柴油最新零售限价及较上轮调价涨跌（涨红跌绿） |
| 🗺️ 全国 31 省市 | 下拉切换地区；全国油价表格支持搜索省份、点击表头排序、当前地区高亮 |
| ⏰ 调价倒计时 | 下次调价窗口日期与倒计时天数、后续窗口、上次调价幅度、年度累计与「涨跌搁浅」格局 |
| 📈 历史油价 | 2026 年全年调价走势图（汽油/柴油累计变动）+ 逐次调价明细（含约合 92# 每升变动） |

## 快速开始

无需服务器、无需安装依赖，双击 `index.html` 即可在浏览器中打开使用。

## 技术说明

- **技术栈**：纯 HTML + CSS + 原生 JavaScript，零依赖单文件（约 20 KB）
- **实时数据**：[xxapi 免费油价接口](https://xxapi.cn)（免 key，一次返回全国 31 省数据）
- **兜底数据**：内置油价快照，在线接口不可用时自动切换，保证页面始终可用
- **IP 定位**：pconline JSONP 接口（主）→ geojs.io（备）→ ipapi.co（备），定位失败不影响数据展示
- **图表**：手绘 SVG 折线图，无第三方图表库
- **调价机制**：依据国家发改委「十个工作日一调」的成品油价格机制，调价窗口与历史记录静态内置

## 数据来源与免责声明

油价数据来源于公开接口与发改委调价信息整理，为各省市**最高零售限价参考值**，实际价格以当地加油站为准。本项目仅供学习与个人使用。
